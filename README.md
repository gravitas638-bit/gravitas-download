# Gravitas – download

Programmi di installazione di **Gravitas**, lista pesi e baricentro per yacht. Versione **0.18.0**.

| File | Per |
|---|---|
| `Gravitas-Setup.exe` | Windows 10 e 11 (programma + plug-in per Rhino) |
| `Gravitas-Mac.zip` | Mac, macOS 10.15 o più recente (in prova: leggi `COME-PROVARE-SU-MAC.txt`) |
| `Gravitas-Rhino.yak` | plug-in per Rhino su Mac (si trascina sulla finestra di Rhino) |

Per usare Gravitas serve un account con una licenza attiva: https://gravitas-lista-pesi.netlify.app
